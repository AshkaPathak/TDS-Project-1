# Contributing

This repository is a project archive, so contributions should improve clarity, reproducibility, or navigation without changing the meaning of completed answers.

## Guidelines

- Keep edits scoped to the relevant project/question folder.
- Update README files when a method, artifact, command, or verification step changes.
- Keep generated outputs and large binary artifacts out of commits unless the project question requires them.
- Do not commit secrets, tokens, local environment files, or private credentials.
- Preserve original problem statements and final-answer records unless the goal is explicitly to correct documentation.

## Good README Pattern

1. Problem/task summary
2. Method used
3. Files and artifacts
4. Run or reproduce commands
5. Verification notes
